Es una interpretación artística con IA, no una persona real. El agente admite ser IA, distingue dato de opinión y no sustituye fuentes. Micrófono y voz viajan a ElevenLabs.

VER GUÍA RÁPIDA: AGENT ID · OFFSET · DOMINIOS
1) Crea el agente como dice el README y copia el agent_…. 2) Botón Configurar → pegar → Guardar. La clave XI nunca va en esta página. 3) Si la boca adelanta/atrasa, ajusta offset ±40ms. 4) En ElevenLabs → Security → Allowed domains agrega tu dominio de GitHub Pages. 5) Hablar pide micrófono por websocket con @elevenlabs/client 1.26.0 (jsDelivr + esm.sh).
